## Blocked: real screen capture

Real screens could not be captured in this session for two reasons, both outside the repository:

1. The cloud environment's network policy denies `qfklkkzxemsbeniyugiz.supabase.co` (and `app.kisanshaktiai.in`, `www.kisanshaktiai.in`). The product apps cannot authenticate or load data from this container. Allow that host in the environment's network settings to unblock.
2. The test farmer account (mobile number and PIN) and tenant/admin sign-in credentials were not provided.

`scripts/capture-screens.mjs` is ready: with the three dev servers running and credentials in the environment it captures every screen listed in `src/content/screens.ts`, converts to WebP and marks them captured. Until then every device frame on the site shows an explicit "Capture pending" tile with the screen's name and question, never a mock.
